# AI-STAT Lab Website

Simple static landing page for **aistatlab.com**.

## Preview locally

Open `index.html` in a browser.

## Publish with GitHub Pages

1. Create a GitHub repository named `aistatlab-web`.
2. Upload/push all files from this folder.
3. In GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. Under **Custom domain**, enter `aistatlab.com`.
7. Configure the required DNS records at your domain registrar.
8. After DNS verification, enable **Enforce HTTPS**.

The included `CNAME` file contains `aistatlab.com`.
